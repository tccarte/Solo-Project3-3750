Python/Flask backend with a JSON file for storage, vanilla HTML/CSS/JS frontend.

MTG Collection Manager is a web app for tracking your Magic: The Gathering card collection. You can add, edit, and delete cards while recording details like set, mana value, color, rarity, quantity, and condition. The app includes search and color filtering, pagination, and a stats page that shows collection totals, average mana value, color distribution, and rarity breakdown.
